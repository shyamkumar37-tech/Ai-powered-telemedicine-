# Release v1.0.0 — Initial Release & Real-Time Consultation

## Summary
Initial release of **TeleCare+**, introducing multi-role portal management, WebRTC audio/video consultations, and Spring Boot 3 & React 18 base architecture.

## What's Included
- **Multi-Role Portal**: Patient, Doctor, Caregiver, Pharmacist, and Admin dashboards.
- **Real-Time Consultations**: P2P WebRTC audio/video calls with WebSocket signaling.
- **Health Records**: Vitals logging (BP, SpO2, Heart Rate, Glucose).
- **Core Messaging**: Real-time STOMP chat and notification dispatching.
