# Release v1.1.0 — Security & Performance Optimizations

## Summary
Performance and security hardening release, introducing Java 21 Virtual Threads, Spring Modulith boundary decoupling, and HIPAA access audit logging.

## What's Included
- **Spring Modulith Decoupling**: 100% boundary isolation across domain slices with zero cyclic package dependencies.
- **Java 21 Virtual Threads (`Loom`)**: Enabled high-throughput concurrent request handling (`spring.threads.virtual.enabled=true`).
- **Security Hardening**: `@AuditLog` HIPAA access tracking, stateless JWT bearer tokens, and `HttpOnly` CSRF protection cookies.
- **Redis Caching**: Caching layer for active user sessions and dashboard statistics.
